# Configuration Firewall 🛡️

## ❓ Problème
Comment sécuriser le périmètre réseau et isoler les segments critiques (VLANs, DMZ) ?

## 🛠️ Solution
Mise en œuvre de règles de filtrage (Stateful Packet Inspection) et de politiques d'accès restrictives.

## 🧪 Environnement
- **Équipement** : pfSense / OPNsense / FortiGate (Virtuel)
- **Règles** : Segmentation L3, NAT, Anti-spoofing

## 🎯 Résultats / apprentissages
- Mise en place du principe de moindre privilège.
- Analyse des logs de trafic pour l'ajustement des politiques.
- Sécurisation des flux entrants et sortants.
