# Configuration VyOS 🌐

## ❓ Problème
Comment centraliser et versionner les configurations de routage et de services réseau (DHCP, DNS, VPN) ?

## 🛠️ Solution
Exportation des configurations VyOS au format texte (commands) pour un suivi précis des modifications.

## 🧪 Environnement
- **Routeur** : VyOS 1.3 LTS
- **Fonctions** : Routage inter-VLAN, NAT, Firewall, WireGuard VPN

## 🎯 Résultats / apprentissages
- Maîtrise de la CLI VyOS.
- Versioning des changements réseau critiques.
- Facilité de déploiement et de restauration.
