# Configurations Réseau et Sécurité ⚙️

Ce dossier contient les fichiers de configuration pour les différents composants de l'infrastructure NEXWARDEN.

## 📂 Structure
- `vyos/` : Routage et services réseau.
- `firewall/` : Règles de filtrage et NAT.
- `vlan/` : Segmentation réseau et Trunking.

## 🎯 Objectif
Fournir un point de référence central pour l'administration et la reproductibilité des environnements de lab.
