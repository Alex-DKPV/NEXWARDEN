# Scripts de Durcissement (Hardening) ⚙️

## ❓ Problème
Comment automatiser la sécurisation d'un système Linux ou Windows pour réduire la surface d'attaque ?

## 🛠️ Solution
Collection de scripts Bash et PowerShell appliquant les meilleures pratiques de durcissement (CIS Benchmarks, ANSSI).

## 🧪 Environnement
- **Systèmes** : Ubuntu 22.04 LTS, Windows Server 2022
- **Langages** : Bash, PowerShell, Python
- **Outils** : Lynis, CIS-CAT Lite

## 🎯 Résultats / apprentissages
- Automatisation du durcissement SSH, pare-feu et gestion des utilisateurs.
- Réduction significative des vulnérabilités système détectées par audit.
- Conformité accrue aux standards de sécurité internationaux.
