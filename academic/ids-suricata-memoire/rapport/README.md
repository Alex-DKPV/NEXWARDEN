## 📝 Résumé Exécutif

**Sujet** : Mise en place d'un système de détection d'intrusions (IDS) basé sur Suricata dans un environnement Linux virtualisé.

**Objectifs atteints** :
- Déploiement et configuration complète de Suricata
- Création de règles personnalisées de détection
- Intégration avec stack de monitoring (Wireshark, EVE JSON)
- Tests de détection avec simulations d'attaques réelles
- Étude comparative Snort vs Suricata

## 📚 Méthodologie

1. **Phase 1** — Étude bibliographique et comparative IDS
2. **Phase 2** — Déploiement environnement virtualisé (VMware)
3. **Phase 3** — Configuration Suricata + règles personnalisées
4. **Phase 4** — Tests et simulations d'attaques
5. **Phase 5** — Analyse des résultats et rédaction
